# 练习：用 Triton 实现按行求和

给定一个二维矩阵，计算每一行所有元素的和。

例如：

```
输入：
[[1, 2, 3],
 [4, 5, 6]]

输出：
[6, 15]
```

**输入与输出：**

* 输入：形状为 `[N, D]`、连续存储的 CUDA 张量，类型为 FP32。
* 输出：形状为 `[N]` 的 CUDA 张量，类型为 FP32。
* `N、D` 均为正整数。

**实现要求：**

1. 编写一个 Triton 内核，以及调用它的 Python 包装函数。
2. 每个程序实例负责若干行，行块大小通过参数指定。
3. 每个实例沿列方向分段读取，列块大小也通过参数指定。
4. 将各段的求和结果累加，最后每行写回一个数。
5. 正确处理不足一个行块或列块的情况。

行块、列块大小先选择 **2 的幂**，实际求和由 Triton 内核完成。

**验证用例：**


| 输入形状`[N, D]` | 行块大小 | 列块大小 | 检查内容                   |
| ---------------- | -------- | -------- | -------------------------- |
| `[4, 8]`         | 2        | 4        | 行、列都能整除             |
| `[5, 10]`        | 2        | 4        | 最后一个行块、列块都不完整 |
| `[3, 5]`         | 4        | 8        | 整个输入小于一个块         |

每组结果都与 PyTorch 参考结果比较：

```
expected = x.sum(dim=1)
torch.testing.assert_close(actual, expected, rtol=1e-4, atol=1e-4)
```

**完成标准：**

1. 三组用例均通过。
2. 能说明当前实例负责哪些行、每轮读取哪些列，以及越界位置怎样处理。
